# Getting Started

## Install from source

```bash
python -m pip install -e .
```

## Install with docs extras

```bash
python -m pip install -e .[docs]
```

## Run tests

```bash
pytest
```

## Build docs locally

```bash
mkdocs serve
```

Then open the local URL shown in the terminal (typically `http://127.0.0.1:8000`).
