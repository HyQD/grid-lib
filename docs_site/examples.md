# Examples

The repository includes a broad set of scripts under `examples/`.

Representative examples:

- stationary-state calculations,
- imaginary-time propagation,
- dipole and beyond-dipole interactions,
- molecular potentials and matrix elements.

To run an example from the repository root:

```bash
python examples/stationary_states.py
```

For notebook-based walkthroughs, see the [Notebooks](notebooks/stationary_states_cylindrical_coordinates.ipynb) section.
