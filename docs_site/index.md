# HyQD Grid Library

The HyQD Grid Library provides grid-based numerical tools for quantum dynamics and structure calculations.

This documentation site contains:

- theory notes used by the library implementation,
- runnable examples and notebooks,
- API reference generated directly from source code docstrings.

## Why this docs setup

This site is built with MkDocs and deployed automatically to GitHub Pages from CI. The goals are:

- simple maintenance,
- quick local preview,
- API docs synchronized with code,
- readable math-heavy pages.
